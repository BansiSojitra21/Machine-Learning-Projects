# Regression Projects

This folder contains my **Machine Learning Regression projects**, focused on predicting continuous numerical values using different machine learning algorithms.

Each project follows a complete machine learning workflow, including **data cleaning, exploratory data analysis, feature engineering, preprocessing, model training, evaluation, model comparison, and prediction**.

## 📂 Projects

### ✅ Completed

* 📊 **[Student Performance Prediction](./Student Performance/)**
  Predicts student performance based on various academic and personal factors.

* 💻 **Laptop Price Prediction**

## 🛠️ Machine Learning Workflow

Projects generally include:

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Missing Value Handling
5. Outlier Detection & Treatment
6. Feature Engineering
7. Categorical Encoding
8. Feature Scaling
9. Train-Test-Unseen Data Split
10. Model Training
11. Model Evaluation
12. Model Comparison
13. Hyperparameter Tuning
14. Final Prediction

## 🤖 Regression Algorithms

Depending on the project, I experiment with:

* Linear Regression
* Ridge Regression
* Lasso Regression
* Polynomial Regression
* Decision Tree Regressor
* Random Forest Regressor
* Gradient Boosting Regressor
* AdaBoost Regressor
* XGBoost Regressor
* CatBoost Regressor
* Support Vector Regression (SVR)
* K-Nearest Neighbors (KNN) Regression

## 📈 Evaluation Metrics

The regression models are evaluated using:

* **R² Score**
* **Mean Absolute Error (MAE)**
* **Mean Squared Error (MSE)**
* **Root Mean Squared Error (RMSE)**

These metrics are used to compare models and measure their prediction performance.
