# 📊 Classification Projects

Welcome to the **Classification** section of my Machine Learning portfolio.

This directory contains machine learning projects focused on predicting **categorical outcomes**. Each project follows a complete end-to-end machine learning workflow, including data preprocessing, feature engineering, model training, hyperparameter tuning, and performance evaluation.

---

# 📌 What You'll Find

Each project includes:

* 📂 Dataset
* 🧹 Data Cleaning
* 📊 Exploratory Data Analysis (EDA)
* ⚙️ Feature Engineering
* 🔤 Encoding & Feature Scaling
* ✂️ Train-Test Split
* 🤖 Multiple Classification Models
* 🎯 Hyperparameter Tuning
* 📈 Model Evaluation
* 💾 Saved Best Model (where applicable)
* 📝 Detailed Documentation

---

# 🤖 Classification Algorithms

Depending on the project, one or more of the following algorithms are used:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* Naive Bayes
* Gradient Boosting
* AdaBoost
* XGBoost
* CatBoost
* LightGBM

---

# 📊 Evaluation Metrics

The models are evaluated using appropriate classification metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC Score
* Confusion Matrix
* Classification Report
