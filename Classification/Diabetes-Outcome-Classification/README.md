# 🩺 Diabetes Classification

An end-to-end Machine Learning project that predicts whether a patient is likely to have diabetes based on various medical attributes. This project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, hyperparameter tuning, and model evaluation.

---

# 📌 Project Overview

Diabetes is one of the most common chronic diseases worldwide. Early prediction can help healthcare professionals take preventive measures and improve patient outcomes.

The objective of this project is to build a classification model capable of predicting diabetes using patient health data.

---

# 🎯 Problem Statement

Develop a machine learning model that accurately classifies whether a patient is diabetic based on medical features.

---

# 📂 Dataset

The dataset contains patient medical information along with the target variable indicating whether the patient has diabetes.

**Target Variable**

* **Outcome**

  * `0` → Non-Diabetic
  * `1` → Diabetic

# 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/Diabetes-Classification.git
```

2. Navigate to the project folder.

```bash
cd Diabetes-Classification
```

3. Install the required libraries.

```bash
pip install -r requirements.txt
```

4. Open the Jupyter Notebook.

```bash
jupyter notebook
```

5. Run **Diabetes_Classification.ipynb**.
